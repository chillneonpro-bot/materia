# Contribuer à Materia

1. Créez une branche depuis `main`.
2. Installez le projet avec `python launcher.py`, puis arrêtez le serveur.
3. Exécutez `python -m pytest -q` dans l'environnement virtuel.
4. Documentez la source, le grade, la norme, le conditionnement et le domaine de toute nouvelle donnée matériau.
5. Ouvrez une pull request avec le problème résolu et les contrôles effectués.

Une fiche fabricant peut documenter un module initial. Elle ne doit jamais être présentée comme une preuve de cinétique de vieillissement sans série temporelle compatible.
