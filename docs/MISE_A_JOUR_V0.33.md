# Materia v0.33 — carte de preuve exportable

## Une page pour justifier un résultat

Tous les parcours qui produisent une courbe proposent maintenant le bouton **Carte de preuve**. Le PDF tient sur une page A4 et présente les informations nécessaires pour relire ou joindre le résultat à un compte rendu :

- valeur du module à l’horizon et pourcentage conservé ;
- origine de la valeur : observée, interpolée, estimée ou extrapolée ;
- matériau, propriété, grade, procédé, horizon et modèle ;
- fenêtre de preuve, conditions et protocole disponibles ;
- niveau de preuve et nature de l’incertitude ;
- source primaire, DOI ou URL ;
- limites d’usage et empreinte reproductible du calcul.

La carte est disponible pour les projections sur fiche, les mesures publiées, les observations importées, les exercices pédagogiques et les projets enregistrés. Elle complète le rapport PDF détaillé et le classeur Excel sans modifier le calcul scientifique.

## Contrôles

Un test automatique vérifie que la carte reste sur une seule page et conserve l’origine du point, le DOI et l’empreinte du résultat. La suite complète compte 109 tests validés.
