# Materia v0.31 — origine de chaque valeur

La v0.31 indique comment chaque point d’une courbe a été obtenu :

- **Observé** : valeur présente dans la série source ;
- **Interpolé** : valeur calculée entre des données ou dans la fenêtre documentaire ;
- **Extrapolé** : valeur située après la fenêtre documentaire ;
- **Estimé** : projection issue des hypothèses génériques d’une famille ;
- **Synthétique** : valeur d’un exercice pédagogique fictif.

Le statut de la valeur à l’horizon apparaît près du niveau de preuve. La table accessible de la courbe et les exports Excel, PDF et étudiant conservent également cette information. Le calcul numérique des courbes n’a pas été modifié.
