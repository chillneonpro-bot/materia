# Materia v0.45 — interface simplifiée

La version 0.45 réduit la charge visuelle sans retirer de paramètre ni de fonction.

## Simuler

- cinq choix restent visibles : matériau, température, milieu, durée et seuil ;
- le module initial, l’humidité, l’épaisseur, le liquide, le grade et le procédé sont regroupés dans **Paramètres avancés** ;
- le résultat principal contient le temps central, la plage totale de 10 %, le module à l’horizon, la courbe et une phrase de lecture ;
- les valeurs, la validité, les facteurs, les sources et le plan d’expérience sont regroupés dans **Détails et méthode** ;
- les exports Excel, PDF, Markdown, carte de preuve et JSON sont accessibles depuis un seul bouton **Exporter** ;
- les fonctions de prédiction figée et de plan d’expérience restent dans **Outils de recherche**.

## Comparer

- l’humidité et l’épaisseur passent dans les paramètres avancés ;
- le bouton de calcul se trouve avant les résultats ;
- chaque matériau obtient une carte courte avec son pourcentage conservé et son temps au seuil ;
- le tableau complet reste disponible dans **Voir les résultats détaillés**.

## Navigation

La barre latérale conserve quatre entrées principales : **Accueil**, **Simuler**, **Comparer** et **Mes projets**. Les pages Matériaux, Validité, Comprendre, Documents et Données sont regroupées dans **Ressources**. Espace classe et Mon compte restent accessibles dans la zone personnelle.
